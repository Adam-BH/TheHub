Chapitre 1Qu'est-ce que la recherche opérationnelle ?

Allouer au mieux des ressources limitées, avec des maths et un ordinateur.

§1.1Motivation : allocation de ressources

Définition · Management (Daft, 2014)Atteindre les objectifs de l'organisation de façon efficace et efficiente par la planification, l'organisation, la direction et le contrôle des ressources.

Ressources = tous les moyens mis à disposition de l'organisation : humaines, financières, matérielles / immatérielles, technologiques. Fixer l'objectif demande de la stratégie ; allouer les ressources pour l'atteindre, c'est le travail de la RO.

La RO est aussi appelée : science de gestion (management science), science décisionnelle, méthode / algorithme d'optimisation, programmation mathématique.

Exemple · Répartition de tâches2 personnes, 5 tâches (20, 30, 60, 15, 25 min). Une tâche → exactement une personne, une personne → une tâche à la fois. Finir le plus vite possible. Ressources = les 2 personnes, objectif = minimiser le temps de fin.
Exemple · Gestion de projetn ouvriers, m jobs, règles de priorité, jobs partageables, durées qui dépendent de l'ouvrier → combien de jours pour finir le projet ?

Applications industrielles : FedEx (6,5 M d'articles/jour, 220 pays : centres de distribution, tri, itinéraires), Continental Airlines (villes à relier, 2000 vols/jour, affectation des équipages en urgence). Il faut à chaque fois un système d'information bien conçu + de la RO.

§1.2Définitions de la RO

Définition« La RO est la science qui applique des outils mathématiques et informatiques pour aider à la prise de décision. » (Operations Research Society of America)
Autres : décider scientifiquement comment concevoir et faire fonctionner des systèmes homme-machine nécessitant l'allocation de ressources rares · base quantitative pour les décisions (Morse & Kimball) · « l'art de donner de mauvaises réponses à des problèmes où sinon on en donnerait de pires » (T.L. Saaty).

§1.3Business analytics : 4 niveaux

NiveauQuestionOutils

Rétrospectif / orienté information → prospectif / orienté décision. Analyse de données = recueillir l'information et comprendre le problème ; RO = allouer les ressources et résoudre le problème.

Optimisation (OPT)Trouver la valeur min (ou max) d'une fonction objectif soumise à des contraintes. + techniques exactes et insights. − modèles simples, hypothèses strictes.
Simulation (SIM)« What if », scénarios. + complexité et aléas réels. − on évalue seulement des scénarios donnés.

Inventaire multi-produits : 1 produit → estimer la demande aléatoire puis choisir le niveau de stock (éviter sous-stockage / surstockage) ; plusieurs produits → substitution dans la demande (« plus de coca ? un pepsi ») : analyse de données et RO deviennent difficiles.

§1.4Processus d'une étude RO

Définir le problème→Collecter les données→ suffisantes ? →Formuler un modèle→Résoudre→ bon modèle ? →Interpréter, suggérer

Si les données ne suffisent pas → on recollecte ; si le modèle n'est pas bon → on reformule. Avantages du modèle : décrit le problème précisément, permet de le résoudre par ordinateur. Limites : certains problèmes sont difficiles à formuler, des informations essentielles peuvent manquer.

§1.5Programmation mathématique : le sac à dos

Sac de 5 kg, 7 articles indivisibles (pris ou laissés). Le choix glouton par rapport valeur/poids donne 1,2,3,4,5 (valeur 22) ; l'optimum est 1,2,3,4,6 (valeur 23) → l'intuition ne suffit pas, il faut un modèle.

xi = 1 si l'article i est choisi, 0 sinon ← variables de décision (binaires) max 6x₁ + 5x₂ + 4x₃ + 4x₄ + 3x₅ + 4x₆ + x₇ ← fonction objectif s.c. 0.5x₁ + 1.5x₂ + 0.4x₃ + x₄ + 1.1x₅ + 1.6x₆ + 0.8x₇ ≤ 5 ← contrainte xi ∈ {0,1} ∀ i = 1..7
Formulation compactemax Σ vixi s.c. Σ wixi ≤ B, xi ∈ {0,1}
wi = poids, vi = valeur, n = nb d'articles, B = poids max. Paramètres (données) ≠ variables (décisions).

Même modèle, autre sens : sélection des commandes (wi = temps de traitement, vi = bénéfice, B = capacité de l'usine) · optimisation de portefeuille : investissement « pas tout ou rien » → 0 ≤ xi ≤ 1 (variable continue).

Méthodes exactes : simplexe de Dantzig, méthodes primales/duales, Branch and Bound, Branch and Cut, programmation dynamique ; non linéaire : gradient, gradient conjugué, Newton… Métaheuristiques (approchées) : recherche tabou, recuit simulé, hill-climbing, algorithmes génétiques, colonies de fourmis, essaims particulaires.

§1.7Histoire

George Dantzig (1914–2005) planifiait les itinéraires de l'US Air Force pendant la 2e Guerre mondiale ; chaque plan s'appelait un « programme » (d'où « programmation » linéaire). Il invente la méthode du simplexe, toujours au cœur des solveurs. Kantorovich et Koopmans : Nobel d'économie 1975 (allocation optimale des ressources). Succès PL : United Airlines (−50 % de retards, 5 M$/an, 1992), Swift & Company (+12 M$/an, 2006).

Chapitre 2 · Section 1Terminologie d'un programme linéaire

Les mots du DS : chaque terme ici tombe en QCM ou en vrai/faux.

§2.1Programme linéaire (PL / LP)

DéfinitionLa programmation linéaire est le processus de formulation et de résolution de programmes linéaires. Un PL est un programme mathématique où la fonction objectif et les contraintes sont linéaires et les variables continues (réelles).
min (ou max) f(x₁, …, xₙ) fonction objectif (FO / fonction économique) s.c. gi(x₁, …, xₙ) ≤ bi ∀ i = 1..m contraintes fonctionnelles xj ∈ ℝ ∀ j = 1..n variables de décision

s.t. (subject to) = s.c. (sous contraintes). Les 3 éléments d'un PL : variables de décision, fonction objectif, contraintes.

§2.2Types de contraintes

Contrainte de signeNe porte que sur une variable comparée à 0 :
• positive xi ≥ 0 (non-négativité)
• négative xi ≤ 0
• sans restriction de signe (xi ∈ ℝ, « libre »)
Contrainte fonctionnelleToutes les autres : x₂ ≤ 3, x₁ + 2x₂ ≥ 5, 4x₂ = 5… Même x₂ ≤ 3 est fonctionnelle (le second membre n'est pas 0).
Transformation max ↔ minmax f(x) ⇔ − min (−f(x)) : même solution optimale x*, valeur opposée.
Une contrainte ≥ se change en ≤ en multipliant par −1 : −2x₁ ≥ 1 ⇔ 2x₁ ≤ −1.

§2.3Solutions

Solution réalisable (admissible)Satisfait toutes les contraintes.
Solution irréalisableViole au moins une contrainte.
Région / domaine réalisableL'ensemble de toutes les solutions réalisables (un polyèdre convexe pour un PL).
Solution optimaleSolution réalisable qui atteint la plus grande valeur de la FO (max) ou la plus petite (min) : aucune solution réalisable n'est meilleure. Elle peut être unique, multiple ou inexistante.

Méthode (exemple du cours avec x¹ = (2,3), x² = (6,0), x³ = (6,6)) : on remplace chaque point dans chaque contrainte, signe compris ; un seul « non » suffit pour qu'il soit irréalisable.

Une solution optimale est toujours réalisable. Un point qui donne une meilleure valeur mais viole une contrainte n'est pas « plus optimal », il est irréalisable.

§2.4Contraintes actives, inactives, strictes, faibles

Contrainte active (liante, saturée)Pour une solution donnée, membre de gauche = membre de droite. Une contrainte d'égalité est toujours active pour toute solution admissible.
Contrainte inactiveL'inégalité est vérifiée strictement pour cette solution (gauche < droite pour ≤) : il reste du « mou ».

Exemples du cours : x₁+x₂ ≤ 10 en (2,8) : 10 = 10 → active. 2x₁+x₂ ≤ 16 en (2,8) : 12 < 16 → inactive. x₁+3x₂ ≤ 9 en (6,1) : 9 = 9 → active.

Inégalité stricte vs faibleStricte (<, >) : les deux côtés ne peuvent pas être égaux. Faible / souple (≤, ≥) : égalité permise. Dans un PL pratique, toutes les inégalités sont faibles : avec une inégalité stricte, l'optimum peut ne pas exister (ex. min x s.c. x > 0 : pas de minimum). Budget : « ne pas dépasser 500 D » mais on peut dépenser exactement 500 D → ≤.
Ne confonds pas contrainte stricte (type d'inégalité, propriété du modèle) et contrainte inactive (propriété d'un point précis).

§2.6Forme standard et variables d'écart

Forme standard (étape 1 du simplexe)Toutes les contraintes fonctionnelles sont des égalités, toutes les variables sont ≥ 0. On y arrive en ajoutant une variable d'écart par contrainte.
Variable d'écart (slack)Pour Σ Aijxⱼ ≤ bi, on pose ei = bi − Σ Aijxⱼ ≥ 0 et on écrit Σ Aijxⱼ + ei = bi.
• Sens : quantité de ressource non utilisée (le « mou »).
• Coefficient 0 dans la fonction objectif.
• ei = 0 ⇔ contrainte i active ; ei > 0 ⇔ inactive.
Exemple du cours (simplexe) max 30x₁ + 50x₂ max 30x₁ + 50x₂ + 0x₃ + 0x₄ + 0x₅ s.c. 3x₁ + 2x₂ ≤ 1800 ⟹ s.c. 3x₁ + 2x₂ + x₃ = 1800 x₁ ≤ 400 x₁ + x₄ = 400 x₂ ≤ 600 x₂ + x₅ = 600 x₁, x₂ ≥ 0 x₁, …, x₅ ≥ 0 x₃, x₄, x₅ = variables d'écart
Complément · contrainte ≥Pour Σ Aijxⱼ ≥ bi on retranche une variable d'excédent (surplus) : Σ Aijxⱼ − ei = bi, ei ≥ 0. Elle ne donne pas de base de départ évidente : il faut une variable artificielle (méthode des deux phases / grand M), hors des diapos du cours.
Lire les écarts à l'optimum, c'est lire les contraintes actives : dans l'exemple, à x* = (200, 600) on a x₃ = 0, x₅ = 0 (ressources 1 et 3 épuisées, contraintes actives) et x₄ = 200 (il reste 200 unités sur la contrainte x₁ ≤ 400, inactive).

Chapitre 2 · Section 2Formulation (modélisation)

« C'est en forgeant qu'on devient forgeron » : une fois bien formulé, le problème est résolu.

§3.1Les 3 questions

Variables de décisionQue peut-on décider ? (quantités à produire, à acheter, à affecter…)
Fonction objectifQue veut-on ? (max profit = revenus − coûts, min coût, min temps)
ContraintesQuelles sont les limites ? (ressources, demande, + contraintes de signe)

§3.2Exemple du cours : soldats et trains

Soldat : vendu 27 D, 10 D de matières premières (MP), 14 D d'autres coûts, 2 h de finition, 1 h de menuiserie. Train : 21 D, 9 D de MP, 10 D d'autres coûts, 1 h de finition, 1 h de menuiserie. Par jour : 100 h de finition, 80 h de menuiserie, au plus 40 soldats vendus, demande de trains illimitée. Maximiser le profit quotidien.

x₁ = nb de soldats produits par jour, x₂ = nb de trains produits par jour max z = 3x₁ + 2x₂ profit = (27−10−14)x₁ + (21−9−10)x₂ s.c. 2x₁ + x₂ ≤ 100 heures de finition x₁ + x₂ ≤ 80 heures de menuiserie x₁ ≤ 40 demande max de soldats x₁, x₂ ≥ 0 restrictions de signe
Les conseils de la prof : définir clairement les variables (avec l'unité et la période : « par jour »), écrire un commentaire après la FO et chaque contrainte, utiliser la même unité partout.
La FO est un profit : revenus − tous les coûts variables. Écrire max 27x₁ + 21x₂ (le chiffre d'affaires) est faux.

§3.3Interprétation d'une solution fractionnaire

Si l'optimum était (20,25 ; 60,5) : produire 20,25 soldats par jour en moyenne (2025 soldats / 100 jours). En pratique on arrondit vers le réalisable : 20 soldats et 60 trains (pas 21 et 61, qui peuvent violer les contraintes). Pas forcément optimal, mais une bonne suggestion trouvée vite. Si l'intégrité est indispensable → PLNE (chapitre 3).

Chapitre 2 · Section 3.1Résolution graphique

Seulement quand le PL a deux variables de décision ; sinon → simplexe.

§4.1Les 5 étapes

  1. Dessiner le domaine réalisable : chaque contrainte = une droite (hyperplan) + le demi-plan du bon côté ; intersection avec x ≥ 0.
  2. Tracer une ligne isoquante (isoprofit pour max, isocoût pour min) : tous ses points donnent la même valeur z = k. Elles sont toutes parallèles.
  3. Indiquer la direction qui augmente z (max) ou la diminue (min) : le vecteur (c₁, c₂).
  4. Pousser l'isoquante jusqu'à la « fin » du domaine : s'arrêter juste avant que tous ses points deviennent irréalisables.
  5. Identifier les contraintes actives à la solution optimale et résoudre le système pour avoir les coordonnées exactes.

Soldats/trains : sommets (0,0), (40,0), (40,20), (20,60) → z* = 180, (0,80). Actives en (20,60) : finition et menuiserie.

contraintesisoquante z = kdirection (c₁,c₂) / optimumdomaine réalisable

§4.2Trois types de PL

Finiment optimalIl existe une solution optimale : unique (un sommet) ou multiple (une arête entière, quand l'isoquante est parallèle à une contrainte active).
Non bornéOn peut pousser l'isoquante à l'infini en restant réalisable : z → +∞ (max) ou −∞ (min). Pas de solution optimale.
IrréalisableDomaine réalisable vide : aucune solution réalisable (contraintes contradictoires).
Domaine non borné ≠ PL non borné. Un domaine infini peut avoir un optimum fini si la direction de l'objectif « bute » sur le domaine (essaie Non borné avec le sens min). Mais un PL non borné a forcément un domaine non borné.
Propriété (théorème fondamental)Si un PL a une solution optimale, au moins un sommet (point extrême) du domaine est optimal → il suffit de comparer les sommets. Si deux points sont optimaux, tout le segment qui les relie l'est aussi (infinité de solutions).

Chapitre 2 · Section 4Algorithme du simplexe

Aller de sommet en sommet en améliorant z à chaque pas, en calcul sur un tableau.

§5.1Vocabulaire du tableau

Variables de base (VB)Une par ligne du tableau (m au total) ; leur valeur se lit dans la colonne « solution » (b). Au départ : les variables d'écart.
Variables hors base (VHB)Les n autres, fixées à 0. Au départ : les variables de décision → on part de l'origine (0,0).
Solution de base réalisableVHB = 0, VB = b ≥ 0. Géométriquement c'est un sommet du domaine.
Ligne ZCoefficients de la FO exprimée en VHB (coûts réduits). Sa case « solution » contient −z (convention du cours).

§5.2L'algorithme (cas max, contraintes ≤, b ≥ 0)

  1. Forme standard : ajouter une variable d'écart par contrainte.
  2. 1er tableau : lignes = VB (écarts), colonnes = toutes les variables + solution, dernière ligne Z = cj (0 pour les écarts), case Z/solution = 0.
  3. Variable entrante : la VHB ayant le plus grand coefficient positif dans la ligne Z → colonne pivot c.
  4. Variable sortante : rapport bi / Eic pour chaque ligne, on retient le plus petit positif (Eic ≤ 0 → +∞) → ligne pivot l. C'est le test du ratio.
  5. Encadrer le pivot Elc = intersection ligne pivot × colonne pivot.
  6. Diviser la ligne pivot par le pivot : E'lj = Elj / Elc ; la variable entrante remplace la sortante dans la base.
  7. Calculer les autres lignes (y compris Z) : E'ij = Eij − (Eic / Elc) × Elj. La colonne pivot devient (0,…,1,…,0).
  8. Test d'optimalité : tous les coefficients de la ligne Z sont nuls ou négatifs ? Oui → fin, z* = −(case Z). Non → retour à l'étape 3.

colonne pivot (entrante)ligne pivot (sortante)pivot

§5.4Remarques importantes (cas particuliers)

Solution infinie (PL non borné)Une VHB a un coefficient positif dans la ligne Z et tous les coefficients de sa colonne sont nuls ou négatifs : aucun ratio positif, on peut l'augmenter sans limite.
Arête optimale (solutions multiples)À la fin, une VHB a un coefficient nul dans la ligne Z : la faire entrer donne un autre sommet de même z. Tout le segment entre les deux est optimal.
Le test du ratio ne prend que les Eic strictement positifs : 400/0 = +∞ et un dénominateur négatif ne compte pas. Prendre un ratio négatif rend la solution irréalisable (une VB devient négative).
À la fin la case Z vaut −36 000 : z* = +36 000. Ne pas recopier le signe moins.
Pour un minSoit on transforme : min z = −max(−z), soit on choisit le coefficient le plus négatif et on s'arrête quand tous sont ≥ 0. Vérifie la convention attendue à l'examen.

MéthodesComment répondre à…

Une fiche par type de question vu dans la Série 1, le Quiz 2 et le DS 2025.

Comment formuler un PL à partir d'un énoncé ?

  1. Souligner ce qu'on décide → variables xj avec unité et période.
  2. Repérer les données → paramètres (prix, coûts, capacités) ; en formulation compacte, les nommer.
  3. Écrire la FO : max profit unitaire × quantité (revenu − tous les coûts variables) ou min coût.
  4. Une contrainte par ressource limitée : Σ consommation ≤ disponibilité ; puis demande / bornes.
  5. Ajouter les contraintes de signe (x ≥ 0) et, si besoin, l'intégrité (→ PLNE) ou le binaire.
  6. Commenter chaque ligne et vérifier les unités.
Série 1 PL1 (zone agricole) : commencer par calculer le bénéfice par hectare de chaque culture (rendement × prix − coûts eau, machine, main-d'œuvre) puis c'est un PL de production classique.

Comment écrire une contrainte « au plus / au moins p % » ?

  1. Écrire la quantité du composant : Σ tixi (ti = teneur de l'ingrédient i).
  2. La comparer à p % du total : Σ tixi ≥ p · Σ xi.
  3. Si le total est fixé (Σxi = 1000), remplacer : Σ tixi ≥ 1000p → contrainte linéaire.
  4. « Entre a % et b % » = deux contraintes.
DS GL 2025 — médicament (mélange), xi = kg de S1..S4, E1, E2 min 15x₁ + 12x₂ + 18x₃ + 10x₄ + 2x₅ + 1.5x₆ coût total s.c. x₁ + x₂ + x₃ + x₄ + x₅ + x₆ = 1000 lot exact 800 ≤ Σ pai·xi ≤ 850 principe actif 80–85 % 50 ≤ Σ li·xi ≤ 100 liant 5–10 % Σ di·xi ≥ 20 désintégration ≥ 2 % Σ impi·xi ≤ 6 impuretés ≤ 0.6 % x₁ + x₂ + x₃ + x₄ ≥ 900 substances actives ≥ 90 % xi ≥ 0 (teneurs du tableau, en fraction : 95 % → 0.95)
Questions de cours du même DS : c'est un problème de mélange (formulation / blending) ; c'est un PL (kg = variables continues) ; on utilise une méthode exacte (secteur réglementé, coût, sécurité) ; objectif = lot de 1000 kg au coût minimal en respectant les spécifications.

Comment résoudre graphiquement et conclure ?

  1. Pour chaque contrainte, tracer la droite via 2 points (x₁ = 0 puis x₂ = 0) et hachurer le bon côté (tester l'origine).
  2. Tracer une isoquante c₁x₁ + c₂x₂ = k avec un k pratique, flécher la direction (c₁, c₂).
  3. Pousser dans le bon sens ; le dernier point touché = optimum. Lire les 2 contraintes actives.
  4. Résoudre le système 2×2 des contraintes actives → coordonnées exactes, puis z*.
  5. Conclure : unique / multiples (isoquante parallèle à une arête) / non borné / irréalisable.
Quiz 2, Q5 (tables/chaises) : la réponse attendue est un nombre (7 chaises) → ne pas oublier de lire la bonne variable à la fin. Vérifie avec l'outil de l'onglet IV.

Comment savoir si une contrainte est active en un point ?

  1. Substituer le point dans le membre de gauche.
  2. Égal au membre de droite → active (écart = 0) ; strictement à l'intérieur → inactive (écart > 0).
  3. Ne pas oublier les contraintes de signe : en (2, 0), x₂ ≥ 0 (ou x₂ ≤ 0) est active.
Quiz 2, Q1 : en A = (2, 0), 8·2 − 4·0 = 16 → 8x₁ − 4x₂ ≤ 16 active, et la contrainte x₂ ≤ 0 aussi.

Comment dérouler une itération du simplexe sans erreur ?

  1. Ligne Z : prendre le plus grand coefficient positif → colonne pivot.
  2. Calculer tous les ratios bi/Eic (seulement Eic > 0), garder le plus petit → ligne pivot.
  3. Diviser la ligne pivot par le pivot.
  4. Pour chaque autre ligne : nouvelle = ancienne − (son coefficient dans la colonne pivot) × nouvelle ligne pivot.
  5. Vérifier : colonne entrante = vecteur unité, colonne « solution » ≥ 0, case Z diminue (−z plus négatif).
Entraîne-toi avec l'outil de l'onglet V : choisis « Soldats / trains » et refais chaque étape à la main avant de cliquer.

Comment modéliser une planification dans le temps (stock, effectif) ?

  1. Indicer chaque variable par la période i.
  2. Équation de conservation : Si = Si−1 + productioni − demandei (stock ≥ 0 ⇒ demande satisfaite).
  3. Équation d'effectif : NOi = NOi−1 + recrutési − licenciési, avec NO₀ et S₀ connus.
  4. Capacité : productioni ≤ (heures normales + heures sup) / heures par unité ; heures sup ≤ 20·NOi.
  5. FO = somme de tous les coûts sur toutes les périodes.

◆Ponts entre les notions

Graphique ↔ simplexeChaque tableau = un sommet du domaine. Exemple du cours : (0,0) → (0,600) → (200,600). Le simplexe suit les arêtes du polygone.
Écart ↔ contrainte activeVariable d'écart nulle ⇔ contrainte active. Au sommet optimal, les contraintes actives sont celles dont l'écart est hors base.
Isoquante parallèle ↔ coefficient Z nulArête optimale en graphique = VHB à coefficient 0 dans la ligne Z finale.
