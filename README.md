# The Hub

The Hub is a static revision portal made by **Adam Bhouri** for INSAT coursework.

It gathers interactive HTML revision sheets, groups them by folder structure, and presents them in the same warm paper style as the Analyse and Algèbre pages.

## What It Does

- Builds a subject catalogue from the `pages/` directory.
- Reads folders as academic structure: `pages/<level>/<semester>/<subject>.html`.
- Shows search, level filters, semester filters, and a compact folder tree.
- Keeps a shared design language in `assets/design-system.css`.
- Works with plain HTML, CSS, and JavaScript, so it is ready for GitHub Pages.

## How Auto-Indexing Works

The hub tries three strategies:

1. On GitHub Pages, it detects the GitHub repository from the page URL and reads `pages/` through the public GitHub Contents API.
2. On a local static server, it reads the directory listing generated by tools like `python -m http.server`.
3. If opened directly as a local file, it uses the fallback list inside `index.html`.

To add a new subject, place a file like this:

```text
pages/gl2/sem2/probabilite.html
```

Then run the site from a static server or publish it. The new card appears automatically.

## GitHub Pages

1. Create the repository on GitHub.
2. Push this project.
3. In the repository settings, enable GitHub Pages from the root of the default branch.
4. Open the published site.

The GitHub repo link in the hub resolves automatically on normal `github.io` URLs.

For a custom domain, set these optional values in `index.html`:

```html
window.HUB_REPO = { owner: "github-user", repo: "repo-name" };
window.HUB_REPO_URL = "https://github.com/github-user/repo-name";
```

## Notes For Future Pages

For best catalogue cards, each subject page should include:

- a clear `<title>`
- a main `<h1>`
- a short `.subtitle`
- useful `<h2>` or `<h3>` chapter headings

The hub will read those headings when it can and turn them into topic chips.
